# Personal Portfolio Website (HTML & CSS Internship Project)

A responsive personal portfolio for N. Vihas, built with **HTML5 and CSS3 only** (no JavaScript, frameworks or backend).

## Sections
Header/Navigation, Home (hero), About Me, Skills (9 skills), Projects (3 cards), Contact, Footer.

## Features
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Single `style.css` with CSS variables for the colour palette
- CSS Grid for layouts and Flexbox for navigation and chips
- Hover and keyboard-focus states on links, buttons, chips and cards
- Mobile media query at 700px; no horizontal scrolling

## Run it
Open `index.html` in any browser.
